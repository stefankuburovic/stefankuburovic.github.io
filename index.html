After the plan

What I modernize

Every change lands as its own merge request, behind your CI, small enough to review in one sitting.

AngularJS to Angular

AngularJS has had no security fixes since January 2022. I move it to Angular without a rewrite and without a freeze: controllers turned into components while the app still runs on AngularJS, then both frameworks side by side with ngUpgrade, services and components moved bottom up, and AngularJS removed at the end. New features can be written in Angular from the second step on.

ng-checkup counts what is left at every step, and a CI gate keeps the AngularJS part from growing back.

Primo VE to NDE

For libraries on Ex Libris Primo: the AngularJS customization package rebuilt as an Angular module for the New Discovery Experience, view by view, before VE goes away.

Version upgrades

One major at a time with ng update, the follow-up migrations reviewed by hand, and the build green after every step.

Zoneless change detection

OnPush everywhere first, then zone.js out of the bundle and out of the tests.

Signals and NgRx

Classic NgRx and BehaviorSubject services moved to signals or the NgRx signal store, with RxJS bridges for legacy consumers.

Standalone and control flow

NgModules removed, @if and @for instead of *ngIf, signal inputs and outputs.

Karma to Vitest

Deprecated Karma and Jasmine replaced, specs kept green, zone-based test helpers rewritten.

Strict typing

strictNullChecks, strictTemplates and noImplicitAny switched on, staged folder by folder.

Circular dependencies and bundle size

Import cycles cut, eager code made lazy, and the initial bundle measured so it stays small.

CI quality gates

Ratchets that let a count go down but never up, so the codebase does not slide back after I leave.

Free and open source

See where your app stands in one minute

ng-checkup is the tool every health check starts from. Run it on your repository and you get the same graded report, as a page you can share with your team.

npx ng-checkup --report checkup.html
  • Finishes in seconds, even on a large monorepo
  • Reads your code, never changes it; only package names and versions go online
  • Known vulnerabilities from osv.dev, hotspots from your git history
  • Deprecations come from your installed Angular version, not a stale list
  • Recognises AngularJS and hybrid apps, with a migration plan in phases
  • On every pull request: the GitHub Action on the Marketplace, or the GitLab CI/CD component
  • MIT licensed, source on GitHub

Which framework runs on a site

No repository needed: ng-checkup url reads what any browser downloads from a public web app and names AngularJS or Angular with the version, zone.js, React, Vue, Next.js and Nuxt.
